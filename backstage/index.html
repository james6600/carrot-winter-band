✦ STAFF ONLY

관리자 로그인

아이디·비밀번호 확인 후 Authenticator 앱의 6자리 코드를 입력해요.

✦ TWO-STEP

Authenticator 등록

Google Authenticator·Microsoft Authenticator 같은 앱으로 QR 코드를 찍고, 앱에 뜬 6자리 코드를 입력하세요.

  1. 휴대폰에서 Authenticator 앱을 열고 + → QR 코드 스캔
  2. 찍을 수 없으면 설정 키 입력으로 아래 키를 직접 입력
  3. 앱에 생긴 CarrotBandMaker 항목의 6자리 코드 입력
✦ TWO-STEP

인증 코드 입력

Authenticator 앱의 CarrotBandMaker 항목에 뜬 6자리 코드를 입력하세요. 5분 안에 입력해야 해요.

✦ PASSWORD
